# Installing Feral Desktop on Windows - User Guide

## Step 1: Download

1. Go to the Feral Desktop download page
2. Click the big blue **"Download Installer"** button
   - Choose **Windows x64** if you have a regular PC (Intel or AMD processor)
   - Choose **Windows ARM64** if you have a Surface Pro X or ARM-based PC
3. Save the file (it will be named something like `Feral-Desktop-Setup-1.0.0.exe`)

## Step 2: Install

1. **Double-click** the downloaded file
2. If Windows asks "Do you want to allow this app to make changes?", click **Yes**
3. The installer will open with a welcome screen
4. Click **Next**
5. Choose where to install (the default location is fine for most users)
6. Click **Next**
7. Click **Install**
8. Wait a few seconds while it installs
9. When done, make sure "Launch Feral Desktop" is checked
10. Click **Finish**

## Step 3: Use

- **To start Feral Desktop**: 
  - Click the Feral Desktop icon on your desktop, OR
  - Find it in the Start Menu under "Feral Desktop"
- **To sign in**: Use your Feralism community credentials
- **To join rooms**: Click the + button and search for community spaces

## That's it! 

No command line, no technical knowledge needed. Just download, install, and start chatting!

## Troubleshooting

### "Windows protected your PC" message
This happens with new software. Click **More info** then **Run anyway**.

### Which version should I download?
- **Most users**: Download Windows x64
- **Surface Pro X users**: Download Windows ARM64
- **Not sure?**: Download x64 - it works on all Windows PCs

### Can't find the app after installing?
- Check your desktop for the Feral Desktop icon
- Or press the Windows key and type "Feral" to search for it

### Need to uninstall?
- Go to Windows Settings > Apps > Apps & features
- Find "Feral Desktop" and click Uninstall
